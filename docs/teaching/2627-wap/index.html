This page is about the course named:

  • Web Application Programming (506-MI), for master programs IN23, 6 CFUs

I am the teacher for this course temporarily, just for the academic year 26/27.

Program, goals, requirements # ↰

Detailed program # ↰

  • HTML:
    • doctype, elements, tags and attributes.
    • Syntactic, stylistic and usability rules.
    • Use of a validator.
    • Sections, content management, textual semantics.
    • Hyperlinks and images.
    • Tables, divs and spans.
  • CSS:
    • DOM tree and model box.
    • Box level, style sheet syntax and inheritance.
    • Selectors, presumptions and pseudoclasses.
    • CSS properties and counters.
    • Layout, visibility and dimensions.
    • Design with CSS: positioning of blocks, layout and animations with CSS.
  • JavaScript:
    • Browser-side programming concepts.
    • Inclusion of scripts and their execution.
    • Types and typeof.
    • Literal functions, definition, anonymous and function name.
    • Function invocation: method, function, apply and constructor.
    • Parameters: arguments, default, rest, return.
    • Scope: var, global scope, block scope.
    • Hoisting.
    • Closure, Truthy and Falsy, memoization, Array and operators.
    • Inheritance: property based, dynamic inheritance, augmenting, primitives coercion.
    • Access to DOM elements via JavaScript.
    • Ajax and asynchronous communication with the server.
  • JS framework (angular / vue):
    • Introduction to some JavaScript frameworks such as angularjs and Vue.
    • Concepts of Data Binding, directives, routing and communication with REST API.

Goal of the course # ↰

Knowledge and understanding # ↰

  • Know and understand HTML and CSS syntax, ECMAScript 2020 (JavaScript), AJAX communication model.
  • Know and understand the principles and coarse structure of client-side web frameworks.

Applying knowledge and understanding # ↰

  • Choose an appropriate programming language for each step of Web Application Development.
  • Gather and interpret relevant information to decide the proper architectural choices for developing a Web Application.

Making judgements # ↰

  • Gather and interpret relevant information to decide the proper architectural choices for developing a Web Application.

Communication skills # ↰

  • Describe the motivations behind the project choices for developing a Web Application.
  • Formulate and describe the specifications for a Web Application.

Learning skills. # ↰

  • Consume software documentation and usage examples for any development framework for both server and client side development.

Requirements # ↰

  • Foundations of Computer Science Algorithms and Data Structures
  • Computer Networks Databases
  • Programming (advanced)
